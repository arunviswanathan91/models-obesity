Study notes

Data availability

This resource contains saved effect estimates, model diagnostics, simulations, gene signatures and deconvolution quality-control summaries. Tables can be filtered and figures are drawn from the selected data. Manuscript data links Figures 3, 5, 6, S18, S19, S24 and S25 to full feature identities, paired effects, calibration metrics and sensitivity comparisons. Plots are generated on demand from the database using the study’s Python plotting code. To request data, gene signatures or figure files, contact the corresponding author at harikumar@rgcb.res.in.

Interpretation

These are associations with BMI. Bulk RNA–protein concordance does not establish cell-specific protein expression. Conditional PTM effects are not direct measurements of occupancy. RNA-model simulations and paired protein–PTM calibration simulations are reported separately. The PTM calibration includes 250 simulated datasets across five scenarios; it does not establish false-discovery control across the screen.

Reference data and PCA

The signature catalogue contains gene sets used to score deconvolved expression; it is not the single-cell expression reference used by BayesPrism. PCA describes the deconvolved bulk-expression endpoint. PCA shows expression similarity; it does not establish a BMI effect. Alternative QC thresholds describe sensitivity to component inclusion. Deconvolution clustering purity describes within-type cluster concentration and is distinct from tumour purity.

Diagnostics and scope

Failed numerical checks are hidden from effect plots by default. Fine-immune categorical results are labelled provisional. Diagnostic summaries are available; draw-level chain traces and patient-level plots are not included in this release.

Figures display completed analyses; browsing and plotting do not fit models.
